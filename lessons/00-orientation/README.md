# Level 0: オリエンテーション

## 目的

このリポジトリを使った学習の進め方を理解し、Droidに依頼する前に自分で課題を整理する。

## 課題

このリポジトリを対象に、次の内容をDroidへ依頼してください。

> このリポジトリの目的と現在の構成を調査してください。
> 今後、FactoryとDroidを学ぶための最初の改善計画を提案してください。
> 変更はまだ行わず、調査結果、前提、提案、確認が必要な点を分けて説明してください。

その後、提案内容を自分で確認し、次の問いに答えてください。

- Droidはリポジトリの目的を正しく理解していたか
- 追加や変更を提案されたファイルは何か
- その提案を採用するか、採用しないか
- 判断に必要な情報は何か

## 完了条件

- [ ] Droidへの依頼文に目的が含まれている
- [ ] 「変更はまだ行わない」という制約を含めている
- [ ] 調査結果と提案を分けて出力させている
- [ ] 出力内容を自分で確認した
- [ ] 判断理由を `journal/` に記録した
